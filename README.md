# NHN KCP PC 표준결제 연동 포트폴리오


## 파일 구성

- `index.html`: 시맨틱 HTML, 9개 소개 섹션, 논리 아키텍처 도식
- `style.css`: 다크 네이비/블루 디자인, 모바일 반응형, 키보드 포커스, 모션 감소 설정
- `script.js`: 모바일 메뉴, 결제 단계 설명 전환, 탐색 위치 표시
- `assets/favicon.svg`: 자체 제작 공개용 아이콘
- `README.md`: 실행·배포 방법, 검증 범위와 보안 안내

## 로컬 실행

`index.html`을 브라우저로 열면 됩니다. 서버, DB, 패키지 설치, 빌드가 필요하지 않습니다. 인터넷 연결 없이도 동작하며 외부 글꼴·라이브러리·CDN을 사용하지 않습니다.

선택적으로 PowerShell에서 로컬 정적 서버를 실행할 수 있습니다.

```powershell
Set-Location C:\Users\user\projects\kcp-payment-portfolio
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000`에 접속합니다. 종료는 `Ctrl+C`입니다. 이 서버는 정적 파일 미리보기용이며 결제 API가 아닙니다.

## 검증 결과의 의미

페이지의 Python 96개 / JavaScript 7개 통과 수치는 사용자가 제공한 **기존 결제 프로젝트의 최신 테스트 결과**입니다. 이 사이트를 제작하면서 기존 프로젝트 테스트를 실행하거나 원본 코드를 조사한 결과가 아닙니다. 내용과 논리 도식은 제공된 프로젝트 설명을 기준으로 구성했습니다.

- 실제 KCP 테스트 환경 확인: 결제창 호출, 카드 인증·승인, SQLite 저장, 거래조회와 PAID 일치
- 모의 테스트 확인: PAYCO 카드·포인트·혼합결제, 전체취소, 타임아웃·복구, 동시 요청·저장 실패
- 미검증: 실제 PAYCO 승인 성공, 실제 취소 API 성공

사이트의 단계 선택은 설명을 전환할 뿐 실제 결제나 거래조회를 수행하지 않습니다. 도식의 체크 표시는 설명용이며 실시간 시스템 상태가 아닙니다.

## 접근성 및 수동 확인

- 본문 바로가기, 시맨틱 제목, 명확한 키보드 포커스 사용
- 메뉴의 `aria-expanded`, 단계의 `aria-pressed`, 상세 설명의 `aria-live` 제공
- 메뉴는 Enter/Space로 열고 Escape로 닫을 수 있습니다. 단계 버튼은 Tab으로 이동하고 Enter/Space로 선택합니다.
- 모션 감소 설정을 존중합니다. JavaScript 없이도 본문, 메뉴, 전체 흐름 설명을 읽을 수 있습니다.
- 360px 모바일부터 태블릿·데스크톱까지 레이아웃을 확인하고, 확대 200%, 키보드 탐색, 스크린리더 읽기 순서를 최종 검토하는 것을 권장합니다.

## 보안 검토 결과

- 기존 `kcp-standard-pay` 프로젝트를 읽거나 수정하거나 복사하지 않았습니다.
- `.env`, DB, 인증서, 개인키, 토큰 및 실제 주문번호·거래번호를 포함하지 않습니다.
- 거래 샘플 데이터 자체를 사용하지 않으며 모든 화면은 공개 설명과 개념도입니다.
- 결제 API 호출, 외부 네트워크 요청 코드, 분석 도구, 쿠키 및 브라우저 저장소 사용이 없습니다.
- 외부 패키지나 CDN 없이 상대 경로로만 공개 자산을 참조합니다.
- 결제 프로젝트의 보안 설계를 소개하는 것이며 원본 시스템에 대한 보안 감사 인증을 의미하지 않습니다.
